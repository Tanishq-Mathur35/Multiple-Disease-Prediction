# 🧑‍⚕️ Multiple Disease Prediction System

A **machine learning–powered web application** built using **Python** and **Streamlit** that predicts the likelihood of multiple diseases based on user-provided medical data.

🔗 Live App: https://the-disease-prediction-app.streamlit.app/

This project currently supports predictions for:
- ✅ Diabetes
- ✅ Heart Disease
- ✅ Parkinson’s Disease

---

## 🚀 Features

- Interactive and user-friendly web interface
- Multiple disease prediction in a single application
- Pre-trained machine learning models for fast predictions
- Light-themed modern UI
- Real-time results with clear outputs

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **Frontend:** Streamlit  
- **Machine Learning:** Scikit-learn  
- **Data Handling:** Pandas, NumPy  
- **Model Storage:** Pickle
